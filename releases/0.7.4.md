# PlumA 0.7.4

El motor de Docker utiliza Ollama 0.40.17 con una imagen oficial fijada por SHA-256 y las funciones de nube desactivadas. Para reutilizar un motor nativo se necesita Ollama estable 0.35.0 o posterior, un modelo local y la nube desactivada en el servicio. PlumA comprueba estos requisitos al iniciarse y vuelve a verificar el motor y el modelo antes de cada inferencia de texto o imagen.

El registro del OCR indica la página y el número de caracteres descartados. La ficha técnica muestra la huella del envío y el SHA-256 de cada original. Las fichas anteriores conservan su significado.

El paquete de Windows incorpora pypdf 6.21.4. El lanzador, el panel y los scripts proceden del mismo commit que el backend. REVISION.txt identifica ese commit. El archivo .sha256 permite verificar la descarga con Get-FileHash en PowerShell.
